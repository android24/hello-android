# 14.7 输入体验问题：点击无响应、误触、滑动冲突与 Input ANR

学 Input 事件分发，最终是为了定位真实问题。

这一节把常见输入体验问题放在一起：

- 点击无响应。
- 点击穿透。
- 误触。
- 滑动冲突。
- 输入法抢焦点。
- Input ANR。

## 本节剧情钩子

用户不会说：

```text
你的 ACTION_DOWN 被父 ViewGroup 拦截了。
```

用户只会说：

```text
我点了没反应。
这个页面乱跳。
列表怎么滑不动。
刚才好像点到后面的按钮了。
App 卡住了。
```

工程师要做的，就是把这些模糊反馈翻译成可验证的输入链路问题。

## 本节定位

本节把输入事件知识转化为排查清单。

## 学习目标

学完本节后，你应该能够：

- 分类排查点击无响应。
- 区分点击穿透和 View 层级遮挡。
- 用事件序列解释滑动冲突。
- 理解 Input ANR 与主线程阻塞的关系。
- 建立输入问题排查清单。

## 第一部分：点击无响应

点击无响应可能来自很多层：

- View 不可见或不可点击。
- 触摸区域太小。
- 上层 View 遮挡。
- 父 ViewGroup 拦截。
- 子 View 没有消费 DOWN。
- 点击被防抖逻辑拦掉。
- 主线程卡住。
- 当前窗口失去焦点。

排查时不要只看 click 回调，要从事件入口往下看。

## 第二部分：点击穿透

点击穿透常见于弹层、蒙层或动画场景。

表现：

```text
用户点在上层区域，却触发了下层 View。
```

可能原因：

- 上层 View 没有消费事件。
- 蒙层可见但不可点击。
- 弹层关闭时事件继续传递。
- Window flag 或触摸区域设置不符合预期。

解决思路通常是：明确谁应该消费事件，不要让“看得见”和“能接住事件”脱节。

## 第三部分：误触与触摸区域

误触不一定是分发 bug，也可能是体验设计问题。

常见原因：

- 可点击区域太小。
- 相邻按钮太近。
- 滑动和点击阈值不合理。
- 长按、拖拽和点击边界不清。
- 动画过程中点击状态没有禁用。

这类问题需要工程和设计一起处理。

## 第四部分：滑动冲突

滑动冲突通常要看 MOVE。

排查问题：

- DOWN 给了谁？
- MOVE 移动方向是什么？
- 父容器什么时候开始拦截？
- 子 View 是否请求父容器不要拦截？
- 子 View 收到 CANCEL 了吗？

如果只看点击回调，很难解释滑动冲突。

## 第五部分：输入法和焦点

输入法问题也属于输入体验。

常见问题：

- 输入框点了不弹键盘。
- 键盘弹起后遮挡内容。
- 点击空白处键盘不收起。
- Dialog 中输入框焦点异常。

这些问题连接第 13 章窗口知识和第 14 章输入知识：

```text
输入法是窗口，
焦点决定它服务谁，
Insets 决定内容如何适配。
```

## 第六部分：Input ANR

Input ANR 通常意味着：

```text
系统把输入事件交给 App，但 App 没有及时处理。
```

常见原因：

- 主线程长时间计算。
- 主线程等待锁。
- 主线程同步 IO。
- 主线程发起耗时 Binder 调用。
- 首帧或布局绘制过重。

排查时要结合：

- ANR trace。
- 主线程堆栈。
- Logcat。
- 性能工具。
- 用户操作路径。

## 第七部分：输入问题排查清单

遇到输入问题，可以按这个顺序问：

```text
1. 当前窗口是否可见、有焦点、可触摸？
2. 触摸位置是否被其他 View 或 Window 覆盖？
3. Activity.dispatchTouchEvent 是否收到 DOWN？
4. 父 ViewGroup 是否拦截？
5. 子 View 是否消费 DOWN？
6. 事件序列是否出现 CANCEL？
7. 是否存在防抖、禁用、动画中状态？
8. 主线程是否被阻塞？
```

## 本节小挑战

### 问题归类题

请判断下面问题更可能从哪里查：

- 点击按钮没有任何日志。
- Activity 收到 DOWN，但 Button click 不触发。
- 滑动列表时子控件突然收到 CANCEL。
- Dialog 显示时点到了后面页面。
- 点击后 5 秒出现 ANR。

## 本节实践任务

### 基础任务

- 找一个点击无响应案例。
- 从 Activity、父容器、子 View 三层加日志。
- 判断事件断在哪一层。

### 进阶任务

- 模拟一个滑动冲突。
- 记录 DOWN / MOVE / CANCEL / UP。
- 写一份输入问题排查报告。

## 本节小结

输入体验问题看起来分散：点击无响应、点击穿透、误触、滑动冲突、输入法异常、Input ANR。放进输入链路后，它们都能被分类。先确认窗口目标，再确认事件入口，再看 ViewGroup 拦截和 View 消费，最后结合主线程状态，这就是第 14 章要建立的排查能力。
