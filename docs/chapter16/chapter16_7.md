# 16.7 包管理体验问题：安装失败、组件找不到、权限异常与包不可见

前面几节建立了 PMS、安装、Manifest、Intent、签名、权限和状态模型。

这一节把它们放回真实问题：

- 安装失败。
- Activity 找不到。
- 查询不到其他 App。
- 权限明明申请了却不能用。
- 组件明明写了却无法被外部调用。

这些问题看起来分散，但放进包管理链路后，都可以分类排查。

## 本节剧情钩子

测试同学说：

```text
这个 APK 有些手机安装不上。
```

业务同学说：

```text
跳转外部 App 偶现失败。
```

安全同学说：

```text
这个组件为什么能被外部调？
```

你需要把这些问题从“现象”翻译成 PMS 线索。

## 本节定位

本节是第 16 章的问题诊断章节，负责把包管理机制转化成实际排查能力。

## 学习目标

学完本节后，你应该能够：

- 用 PMS 视角分类包管理问题。
- 知道安装失败、组件找不到、权限异常和包不可见的第一证据。
- 能写一份包管理问题诊断报告。
- 建立 Manifest、签名、权限、用户状态和系统版本的联动视角。

## 第一部分：安装失败

安装失败常见原因：

- APK 损坏。
- 包名冲突。
- 签名不一致。
- versionCode 降级。
- ABI 不匹配。
- SDK 不满足。
- 设备策略限制。

排查入口：

```text
安装错误码
  -> 包名和旧包
      -> 签名和 versionCode
          -> APK 结构和 ABI
              -> 系统策略
```

不要只说“卸载重装试试”，要知道为什么重装能解决。

## 第二部分：组件找不到

常见表现：

- ActivityNotFoundException。
- Service 启动失败。
- Receiver 收不到广播。
- Provider 查询失败。

排查入口：

```text
组件是否在 Manifest
  -> merged manifest 是否包含
      -> 组件是否 enabled
          -> exported / permission 是否允许
              -> Intent 匹配是否正确
```

代码存在，不代表系统已注册。

## 第三部分：包不可见

Android 11 后，包可见性会影响查询结果。

表现可能是：

- `getPackageInfo()` 查不到。
- `queryIntentActivities()` 返回空。
- 第三方 App 明明安装，却像不存在。

排查入口：

```text
目标包是否安装
  -> 当前用户是否可用
      -> 调用方是否声明 queries
          -> 查询 Intent 是否匹配
```

包不可见不是目标不存在，而是调用方没有查询视野。

## 第四部分：权限异常

权限问题常见原因：

- Manifest 没声明。
- dangerous 权限未运行时授权。
- signature 权限签名不匹配。
- 组件权限门禁不满足。
- 用户撤销权限。
- 系统版本权限模型变化。

排查入口：

```text
权限是否声明
  -> 保护级别是什么
      -> 是否运行时授权
          -> 调用方签名是否满足
              -> 组件是否额外要求权限
```

## 第五部分：安全暴露问题

包管理问题不只是功能问题，也可能是安全问题。

例如：

- 不该 exported 的 Activity 被外部打开。
- Receiver 被外部伪造广播触发。
- Provider 暴露敏感数据。
- 自定义权限保护级别过低。

排查入口：

```text
组件 exported
  -> intent-filter
      -> permission
          -> 调用方身份
              -> 输入参数校验
```

安全问题要从 Manifest 边界开始看。

## 第六部分：包管理诊断表

| 现象 | 第一证据 | 可能原因 | 修复方向 |
| --- | --- | --- | --- |
| 安装失败 | adb install 错误码 | 签名、版本、ABI、APK 结构 | 按错误码回到安装阶段 |
| Activity 找不到 | Intent 和 Manifest | 未注册、匹配失败、不可见 | 检查 merged manifest 和 intent-filter |
| 查询不到 App | PackageManager 返回空 | Android 11 包可见性 | 增加 queries 或调整查询方式 |
| 权限被拒绝 | Permission Denial 日志 | 未授权、签名不符、组件权限 | 区分声明、授权和保护级别 |
| 外部可访问敏感组件 | exported / permission | 暴露边界过宽 | 关闭 exported 或增加权限门禁 |

## 本节小挑战

### 诊断路线题

请为下面问题写出排查路线：

```text
Android 13 设备上，App 想跳转某第三方支付 App。
开发机正常，测试机 queryIntentActivities 返回空。
```

要求写出：

- 第一证据。
- 可能原因。
- Manifest 里应该检查什么。
- 如何避免直接崩溃。

## 本节实践任务

- 收集一个安装失败错误码。
- 查询它可能发生在哪个安装阶段。
- 写下第一排查证据。

### 进阶任务

- 写一个隐式 Intent 查询实验。

- 写一份包可见性诊断报告。

## 本节小结

包管理体验问题看起来分散，但可以归为安装、组件、权限、可见性和安全边界几类。安装失败看错误码和校验阶段，组件找不到看 Manifest 与 Intent，权限异常看保护级别与授权状态，包不可见看 queries 和用户状态，安全暴露看 exported 与 permission。PMS 视角能把这些问题从经验修复变成证据排查。
